# ELANORA Web Collector Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run a full 18-round ELANORA session from an iPhone against a Muse 2 over Web Bluetooth, uploading raw CSVs that `elanora_data.exe` reads unchanged.

**Architecture:** The phone is the whole instrument — BLE acquisition, audio stimulus, protocol timing, UI. A new C++ executable `elanora_serve` hosts the static page, hands out the round schedule generated by the existing `build_schedule()`, and writes uploaded rounds into `data/datasets/raw/`. The PC is never in the timing path.

**Tech Stack:** Vanilla ES modules (no build step, no npm), Web Bluetooth, Web Audio, IndexedDB, cpp-httplib, C++20/MSVC, Catch2.

**Spec:** `docs/superpowers/specs/2026-09-03-muse-web-interface-design.md`

## Global Constraints

- **No Python or Node in the shipped system.** JavaScript tests run in a browser page, not a test runner.
- **No build step for `web/`.** Plain ES modules served as files. A `<script type="module">` and nothing else.
- **Browser target is Bluefy on iOS.** Desktop Chrome is used only to run the non-BLE tests.
- **CSV columns are ASCII**, comma delimiter, `\n` endings, `.` decimal, header row always, floats at 6 dp.
- **Raw data is never overwritten.** Uploads are additive.
- **Every trial carries a condition label:** `stim`, `control_jitter`, or `control_tone`.
- **Display DSP never reaches a CSV.** Uploaded rows carry raw samples only.
- **Gaps are NaN.** Never bridge, never substitute zero.
- **Sensor naming is fixed:** `S1=TP9`, `S2=AF7`, `S3=AF8`, `S4=TP10`.
- **Trial structure: 30 s baseline / 30 s stimulus / 30 s post**, then 30 s rest.
- **Protocol constants come from `session.hpp`:** `kProtocolFreqLo=0.5`, `kProtocolFreqHi=45.0`, `kProtocolFreqCount=14`, `kProtocolJitter=2`, `kProtocolTone=2`, `kProtocolRounds=18`.

```cpp
// elanora_serve -- hosts the phone collector and receives its recordings.
//
//   elanora_serve --port 8080 --web web --root data/datasets
//
// Binds 0.0.0.0 on purpose: the phone reaches this over the LAN, so binding
// localhost would serve only the machine that cannot do Bluetooth anyway.

#include <cstdio>
#include <cstring>
#include <string>

#include "httplib.h"

int main(int argc, char** argv) {
    int port = 8080;
    std::string web = "web";
    std::string root = "data/datasets";
    for (int i = 1; i < argc; ++i) {
        if (std::strcmp(argv[i], "--port") == 0 && i + 1 < argc) port = std::atoi(argv[++i]);
        else if (std::strcmp(argv[i], "--web") == 0 && i + 1 < argc) web = argv[++i];
        else if (std::strcmp(argv[i], "--root") == 0 && i + 1 < argc) root = argv[++i];
    }

    httplib::Server srv;
    if (!srv.set_mount_point("/", web)) {
        std::fprintf(stderr, "cannot serve %s\n", web.c_str());
        return 1;
    }
    // No caching. The phone must never run a stale copy of the collector
    // after a fix, and silently doing so would look like the fix failed.
    srv.set_post_routing_handler([](const httplib::Request&, httplib::Response& res) {
        res.set_header("Cache-Control", "no-store");
    });
    srv.Get("/health", [](const httplib::Request&, httplib::Response& res) {
        res.set_content("ok", "text/plain");
    });

    std::printf("elanora_serve: http://0.0.0.0:%d  web=%s  root=%s\n",
                port, web.c_str(), root.c_str());
    if (!srv.listen("0.0.0.0", port)) {
        std::fprintf(stderr, "listen failed on port %d\n", port);
        return 1;
    }
    return 0;
}
```

```js
// Muse 2 over Web Bluetooth.
//
// The headset sends a 16-bit sequence number per packet and no clock of any
// kind, so this layer deliberately does not invent timestamps. It reports
// packets; ringbuffer.js turns sequences into a timebase.

export const MUSE_SERVICE = "0000fe8d-0000-1000-8000-00805f9b34fb";

const S = (n) => `273e${n}-4c4d-454d-96be-f03bac821358`;

export const CHAR = {
  control: S("0001"),
  TP9:     S("0003"),
  AF7:     S("0004"),
  AF8:     S("0005"),
  TP10:    S("0006"),
  gyro:    S("0009"),
  accel:   S("000a"),
  telemetry: S("000b"),
  ppgAmbient: S("000f"),
  ppgIr:      S("0010"),
  ppgRed:     S("0011"),
};

// Commands go out length-prefixed with a trailing newline: 0x02 'd' '\n'.
function command(text) {
  const bytes = [text.length + 1];
  for (const ch of text) bytes.push(ch.charCodeAt(0));
  bytes.push(10);
  return new Uint8Array(bytes);
}

export class Muse {
  #device = null;
  #chars = new Map();
  #rawCb = null;

  get connected() {
    return this.#device?.gatt?.connected === true;
  }

  onRaw(cb) { this.#rawCb = cb; }

  async connect() {
    if (!("bluetooth" in navigator)) {
      throw new Error(
        window.isSecureContext
          ? "This browser has no Web Bluetooth. On iOS use Bluefy."
          : "Not a secure context, so Web Bluetooth is unavailable. Use https."
      );
    }
    this.#device = await navigator.bluetooth.requestDevice({
      filters: [{ services: [MUSE_SERVICE] }],
      optionalServices: [MUSE_SERVICE],
    });
    const server = await this.#device.gatt.connect();
    const service = await server.getPrimaryService(MUSE_SERVICE);

    for (const [name, uuid] of Object.entries(CHAR)) {
      try {
        this.#chars.set(name, await service.getCharacteristic(uuid));
      } catch {
        // A characteristic the headset does not expose is not an error --
        // Muse 2016 has no PPG, and the caller decides what it needs.
      }
    }
    if (!this.#chars.has("control")) throw new Error("no control characteristic");
  }

  async #write(text) {
    await this.#chars.get("control").writeValueWithoutResponse(command(text));
  }

  async start() {
    // p50 enables PPG. Sent before "d" because a preset change mid-stream is
    // ignored by the headset.
    await this.#write("p50");
    for (const [name, ch] of this.#chars) {
      if (name === "control") continue;
      await ch.startNotifications();
      ch.addEventListener("characteristicvaluechanged", (e) => {
        this.#rawCb?.(name, e.target.value);
      });
    }
    await this.#write("d");
  }

  async stop() {
    try { await this.#write("h"); } catch { /* already gone */ }
    if (this.#device?.gatt?.connected) this.#device.gatt.disconnect();
  }
}
```

```js
// Packet decode. Pure functions over DataView, so every one is testable
// without a headset.

const EEG_SCALE = 125 / 256;   // 0.48828125 uV per count
const EEG_ZERO = 0x800;        // 12-bit midpoint

// Twelve 12-bit samples packed into 18 bytes: each byte pair-and-a-half holds
// two samples, high nibble first.
export function decodeEeg(dv) {
  const seq = dv.getUint16(0, false);
  const samples = new Array(12);
  for (let i = 0; i < 12; i++) {
    const bit = i * 12;
    const byte = 2 + (bit >> 3);
    const raw = (bit & 7) === 0
      ? (dv.getUint8(byte) << 4) | (dv.getUint8(byte + 1) >> 4)
      : ((dv.getUint8(byte) & 0x0f) << 8) | dv.getUint8(byte + 1);
    samples[i] = (raw - EEG_ZERO) * EEG_SCALE;
  }
  return { seq, samples };
}

// The counter is 16 bits, so at 256 Hz it wraps every ~51 minutes -- inside a
// single 36-minute session plus setup. Left unwrapped, timestamps would jump
// backwards mid-recording.
export function unwrap(prev, seq) {
  const base = prev - (prev % 65536);
  let out = base + seq;
  if (out < prev - 32768) out += 65536;
  if (out > prev + 32768) out -= 65536;
  return out;
}
```

```js
// Six 24-bit big-endian counts. Left raw on purpose: the PPG scale is not
// physically meaningful and every heart feature is computed downstream from
// the raw trace.
export function decodePpg(dv) {
  const seq = dv.getUint16(0, false);
  const samples = new Array(6);
  for (let i = 0; i < 6; i++) {
    const b = 2 + i * 3;
    samples[i] = (dv.getUint8(b) << 16) | (dv.getUint8(b + 1) << 8) | dv.getUint8(b + 2);
  }
  return { seq, samples };
}

// Three triplets of 16-bit signed. Accel scale 1/16384 g, gyro 0.0074768 deg/s.
export function decodeImu(dv, scale) {
  const seq = dv.getUint16(0, false);
  const samples = [];
  for (let i = 0; i < 3; i++) {
    const b = 2 + i * 6;
    samples.push([
      dv.getInt16(b, false) * scale,
      dv.getInt16(b + 2, false) * scale,
      dv.getInt16(b + 4, false) * scale,
    ]);
  }
  return { seq, samples };
}

export const ACCEL_SCALE = 1 / 16384;
export const GYRO_SCALE = 0.0074768;
```

```js
import { unwrap } from "./decode.js";

// One stream's samples on a reconstructed timebase.
//
// The headset supplies no clock, so time comes from the sequence number:
// t = t0 + (seq * perPacket + i) / rate. A missing sequence therefore leaves a
// hole of exactly the right width, which is filled with NaN rather than closed
// up. Closing it up would slide every later sample earlier in time and quietly
// corrupt the alignment between markers and data.
export class Stream {
  #rate; #perPacket; #t0 = 0;
  #first = null; #last = null;
  #v = []; #dropped = 0;

  constructor(rate, perPacket) {
    this.#rate = rate;
    this.#perPacket = perPacket;
  }

  anchor(t0) { this.#t0 = t0; }
  get dropped() { return this.#dropped; }

  push(seq, samples) {
    const u = this.#last === null ? seq : unwrap(this.#last, seq);
    if (this.#first === null) { this.#first = u; this.#last = u - 1; }
    if (u <= this.#last) return;            // duplicate or reordered; ignore

    const missing = u - this.#last - 1;
    for (let k = 0; k < missing * this.#perPacket; k++) this.#v.push(NaN);
    this.#dropped += missing * this.#perPacket;

    for (const x of samples) this.#v.push(x);
    this.#last = u;
  }

  #timeAt(i) {
    return this.#t0 + (this.#first * this.#perPacket + i) / this.#rate;
  }

  slice(t0, t1) {
    const t = [], v = [];
    for (let i = 0; i < this.#v.length; i++) {
      const ts = this.#timeAt(i);
      if (ts < t0) continue;
      if (ts > t1) break;
      t.push(ts); v.push(this.#v[i]);
    }
    return { t, v };
  }
}
```

```js
// Display-only DSP.
//
// Nothing computed here reaches a CSV. Uploads carry raw samples and every
// feature is recomputed by elanora_data, so band powers can never depend on
// which phone ran the session.

const BANDS = [[1, 4], [4, 8], [8, 13], [13, 30], [30, 45]];

function clean(v) {
  const out = [];
  for (const x of v) if (Number.isFinite(x)) out.push(x);
  return out;
}

export function assess(v, sr) {
  const s = clean(v);
  if (s.length < sr / 4) return { quality: "bad", rmsUv: 0, railed: false, flat: true };

  const mean = s.reduce((a, b) => a + b, 0) / s.length;
  let acc = 0, railedCount = 0;
  for (const x of s) {
    const d = x - mean;
    acc += d * d;
    if (Math.abs(x) > 250) railedCount++;
  }
  const rmsUv = Math.sqrt(acc / s.length);
  const flat = rmsUv < 1e-3;
  const railed = railedCount > s.length * 0.05;

  let quality = "bad";
  if (!flat && !railed) {
    if (rmsUv >= 3 && rmsUv <= 50) quality = "good";
    else if (rmsUv > 50 && rmsUv <= 100) quality = "fair";
  }
  return { quality, rmsUv, railed, flat };
}

// Radix-2 FFT, iterative. Small enough that a library would be more code than
// the transform.
function fft(re, im) {
  const n = re.length;
  for (let i = 1, j = 0; i < n; i++) {
    let bit = n >> 1;
    for (; j & bit; bit >>= 1) j ^= bit;
    j ^= bit;
    if (i < j) { [re[i], re[j]] = [re[j], re[i]]; [im[i], im[j]] = [im[j], im[i]]; }
  }
  for (let len = 2; len <= n; len <<= 1) {
    const ang = -2 * Math.PI / len;
    for (let i = 0; i < n; i += len) {
      for (let k = 0; k < len / 2; k++) {
        const c = Math.cos(ang * k), s = Math.sin(ang * k);
        const ur = re[i + k], ui = im[i + k];
        const vr = re[i + k + len / 2] * c - im[i + k + len / 2] * s;
        const vi = re[i + k + len / 2] * s + im[i + k + len / 2] * c;
        re[i + k] = ur + vr; im[i + k] = ui + vi;
        re[i + k + len / 2] = ur - vr; im[i + k + len / 2] = ui - vi;
      }
    }
  }
}

export function bandPowers(v, sr) {
  const s = clean(v);
  const nfft = 256;
  const abs = [0, 0, 0, 0, 0];
  if (s.length < nfft) return { abs, rel: [0, 0, 0, 0, 0], total: 0 };

  const mean = s.reduce((a, b) => a + b, 0) / s.length;
  const step = nfft / 2;
  const psd = new Float64Array(nfft / 2 + 1);
  let segments = 0;

  // Welch: half-overlapping Hann segments, averaged. One periodogram over the
  // whole window would be far noisier at this length.
  for (let off = 0; off + nfft <= s.length; off += step) {
    const re = new Float64Array(nfft), im = new Float64Array(nfft);
    let winPow = 0;
    for (let i = 0; i < nfft; i++) {
      const w = 0.5 - 0.5 * Math.cos(2 * Math.PI * i / (nfft - 1));
      re[i] = (s[off + i] - mean) * w;
      winPow += w * w;
    }
    fft(re, im);
    for (let k = 0; k <= nfft / 2; k++) {
      psd[k] += (re[k] * re[k] + im[k] * im[k]) / (winPow * sr);
    }
    segments++;
  }
  if (!segments) return { abs, rel: [0, 0, 0, 0, 0], total: 0 };

  const df = sr / nfft;
  let total = 0;
  for (let k = 0; k <= nfft / 2; k++) {
    const f = k * df;
    const p = (psd[k] / segments) * df;
    for (let b = 0; b < 5; b++) {
      if (f >= BANDS[b][0] && f < BANDS[b][1]) abs[b] += p;
    }
    if (f >= 1 && f < 45) total += p;
  }
  const rel = abs.map(x => (total > 0 ? x / total : 0));
  return { abs, rel, total };
}
```

- [ ] **Step 3: Write `web/tone.js`**

A sample-by-sample port of `collector/src/tone.cpp`, rendered into an

```js
const TAU = 6.283185307179586;
const CONTINUOUS_SCALE = 0.70710678118654752;   // gated RMS A/2 vs continuous A/sqrt(2)

// xorshift64, matching ToneGenerator::next_jitter_gap so a recorded jitter
// round can be regenerated exactly from its seed.
function xorshift(state) {
  let s = state;
  s ^= (s << 13n) & 0xffffffffffffffffn;
  s ^= s >> 7n;
  s ^= (s << 17n) & 0xffffffffffffffffn;
  return s;
}

export function renderStimulus(ctx, opts) {
  const {
    condition = "stim", hz = 10, rates = null, jitterMeanHz = 10, seed = 1,
    carrierHz = 440, duty = 0.5, seconds = 30, amplitude = 0.5,
  } = opts;

  const sr = ctx.sampleRate;
  const n = Math.round(seconds * sr);
  const buf = ctx.createBuffer(1, n, sr);
  const out = buf.getChannelData(0);

  const rampCoeff = 1 - Math.exp(-1 / (0.004 * sr));
  const dt = 1 / sr;
  const layers = rates ?? [hz];
  const gatePhase = layers.map(() => 0);

  let rng = BigInt(seed || 1);
  const nextGap = () => {
    rng = xorshift(rng);
    const u = Number(rng % 1000000n) / 1000000;
    return (1 / jitterMeanHz) * (1 - duty) * (0.55 + 0.9 * u);
  };

  let env = 0, carrier = 0;
  let jT = 0, jOn = true, jNext = nextGap();
  const jWidth = duty / jitterMeanHz;
  const carrierInc = TAU * carrierHz / sr;

  for (let i = 0; i < n; i++) {
    let target = 0;
    if (condition === "control_tone") {
      target = CONTINUOUS_SCALE;
    } else if (condition === "control_jitter") {
      jT += dt;
      if (!jOn && jT >= jNext) { jOn = true; jT = 0; }
      else if (jOn && jT >= jWidth) { jOn = false; jT = 0; jNext = nextGap(); }
      target = jOn ? 1 : 0;
    } else {
      let sum = 0;
      for (let l = 0; l < layers.length; l++) {
        gatePhase[l] += layers[l] * dt;
        if (gatePhase[l] >= 1) gatePhase[l] -= 1;
        sum += gatePhase[l] < duty ? 1 : 0;
      }
      target = sum / layers.length;
    }

    env += (target - env) * rampCoeff;
    carrier += carrierInc;
    if (carrier >= TAU) carrier -= TAU;
    out[i] = Math.sin(carrier) * env * amplitude;
  }
  return buf;
}
```
