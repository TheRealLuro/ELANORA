Sound
Rhythmic WOO_WOO — hard on/off, silence between. Wave WOOoo_WOOoo — smooth, still reaches silence. Swell WOOOOOOOO — continuous, only breathes in volume, so there is no onset to startle at. All three are equally loud and carry the same rate; run one per session so each can be read on its own.
Frequency coverage
Finer coverage comes from more sessions, not longer ones: each session stays near 36 minutes and takes every Nth frequency, so together they cover the full set. Every session still spans 0.5–45 Hz.

Play four seconds of the real stimulus before you start. There is no way for the app to check this itself — iOS mutes audio downstream of anything the page can see, so a silent session would still record perfect-looking data with no stimulus in it.
Runs on its own. The survey opens after each round.
Before you start
  1. Ringer ON — do not use the silent switch. iOS gives plain web audio a category that obeys that switch, so the stimulus goes mute while everything else keeps playing. The app forces the louder category, but the switch is still the first thing to check if the test tone is silent.
  2. Auto-Lock off. Settings → Display & Brightness → Auto-Lock → Never. A screen lock suspends Bluetooth and audio mid-round, and the round is lost.
  3. Headphones on, volume set once and not touched again. Changing it mid-session makes loudness differ between conditions.
  4. Focus / Do Not Disturb silences notifications, which is what you want — a notification sound landing inside a stimulus window is an uncontrolled auditory event. Turn it on, then run the test tone to confirm the stimulus still sounds.
